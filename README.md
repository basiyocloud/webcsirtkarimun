WEBSITE KARIMUN CSIRT Online

Sistem Layanan Manajemen Informasi Untuk Tim Tanggap Insiden Siber di lingkunga Kabupaten Karimun. mengelola data dan informasi terkait keamanan siber dan update informasi sebagai bagian dari penguatan SPBE dan keamanan Siber. dilengkapi dengan pengaduan secara langsung ke Badan Siber dan Sandi Negara dibantu dengan Pengelola TTIS se Indonesia.
